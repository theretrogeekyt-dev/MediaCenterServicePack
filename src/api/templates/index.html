🌐 DNS Auto-Discovery & Zero-Config Setup Port 53 Active Split-Horizon & DDoS Protected
Connect Windows Media Center automatically on local LAN or across the public internet

MediaCenterServicePack includes an integrated, high-speed DNS server that intercepts legacy Microsoft TV Guide hostnames (data.tvdownload.microsoft.com), Movie metadata (dvd.windowsmedia.com), Music metadata (fai.music.metaservices.microsoft.com), and auto-discovery domains (mediacenter.local, wmc.local). Remote clients over WAN automatically resolve to your public IP while local LAN clients resolve to your private IP.

Public Internet Setup: To allow remote WMC clients to connect over the internet:
  • Forward Port 53 (UDP & TCP) on your router to your NAS/Server LAN IP ({{ dns_server_ip }}).
  • Forward Port 8080 (TCP) on your router to your NAS/Server (or external Port 80 → internal 8080 if your router/ISP supports it).
  • Built-in Response Rate Limiting (RRL) and Authoritative-Only recursion protection prevent open resolver abuse and DDoS attacks automatically!
Windows Media Center Client Sync
One-command client sync and automated daily Task Scheduler configuration

On each Windows 7, 8.1, 10, or 11 machine running Windows Media Center, run the client synchronization script. It downloads guide.mxf, executes loadmxf.exe, and triggers the eHome background indexing service.

Step 1: Run Sync (Auto-Discovery Enabled)

Open PowerShell as Administrator on your Windows Media Center machine. With DNS configured, no server URL is required:

powershell -ExecutionPolicy Bypass -File .\client\sync-wmc.ps1

Or specify the direct server URL manually if not using DNS auto-discovery:

powershell -ExecutionPolicy Bypass -File .\client\sync-wmc.ps1 -ServerUrl http://{{ dns_server_ip }}:{{ port }}

Step 2: Automate Daily Guide Sync via Task Scheduler

To have your WMC guide update automatically every morning at 04:00 AM, paste this into an Administrator Command Prompt:

schtasks /create /tn "MediaCenter-EPG-Sync" /tr "powershell -ExecutionPolicy Bypass -WindowStyle Hidden -File C:\WMC\sync-wmc.ps1 -ServerUrl http://192.168.0.146:8080" /sc daily /st 04:00 /ru SYSTEM /f

Step 3: Verification inside Windows Media Center

  • Open Windows Media Center.
  • Navigate to Tasks → Settings → TV → Guide → About Guide Listings.
  • Verify the listing end date has extended by 48+ hours.
  • Open the Guide grid to confirm channel callsigns, numbers, and program schedules are populated.
