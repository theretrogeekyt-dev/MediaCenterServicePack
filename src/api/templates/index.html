Windows Media Center Ingestion Setup

On your Windows Media Center machine, download and schedule sync-wmc.ps1 to import guide.mxf into loadmxf.exe and refresh the eHome thumbnail cache:

powershell -ExecutionPolicy Bypass -File .\client\sync-wmc.ps1 -ServerUrl http://{{ host_ip }}:{{ port }}

Tip: Create a scheduled task in Windows Task Scheduler running daily at 04:00 AM with the above command.
