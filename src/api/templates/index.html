Windows Media Center Ingestion Setup

On your Windows Media Center machine, execute sync-wmc.ps1 to download guide.mxf, run loadmxf.exe, and refresh the eHome thumbnail cache:

powershell -ExecutionPolicy Bypass -File .\client\sync-wmc.ps1 -ServerUrl http://{{ host_ip }}:{{ port }}

Tip: Create a daily scheduled task in Windows Task Scheduler at 04:00 AM with the above command.
